## The Fix — "We decided to build it ourselves."

**Headline:**
We decided to build it ourselves.

**Body:**

Vitrine started the way most good ideas do — out of frustration.

We were collectors first. Cards, sneakers, watches. The usual suspects. And like everyone else, we were managing our collections across a mess of spreadsheets, screenshots, and group chats.

> "Why isn't there an app that just... gets it?"

We looked. We tried everything. Some apps were too simple. Some were bloated with features no one asked for. Most felt like they were built by people who had never actually collected anything.

So we stopped waiting.

We built Vitrine to be the platform we wished existed. One app for every collection. Built by collectors, for collectors.
